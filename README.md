# Jenkins-Based Digital Wallet Demonstration Platform

## Project Overview

The Jenkins-Based Digital Wallet Demonstration Platform is a web-based application developed to demonstrate digital wallet operations along with a complete DevOps workflow.

The project demonstrates account information, wallet balance management, adding money, wallet refresh operations and transaction-related functionality.

## Technology Stack

- Java
- Jakarta Servlet
- JSP
- Apache Tomcat
- Maven
- Bootstrap
- Git
- GitHub
- Jenkins
- Docker
- Selenium
- Ansible/Puppet
