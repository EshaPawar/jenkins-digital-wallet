TASK 3 – DATA MODEL
JENKINS-BASED DIGITAL WALLET DEMONSTRATION PLATFORM


TABLE 1: users

Field          Type              Constraints
------------------------------------------------------------
id             INT               PRIMARY KEY, AUTO_INCREMENT
name           VARCHAR(100)      NOT NULL
email          VARCHAR(100)      NOT NULL, UNIQUE
mobile         VARCHAR(15)       NOT NULL
password       VARCHAR(255)      NOT NULL
balance        DECIMAL(12,2)     NOT NULL, DEFAULT 0.00
created_at     TIMESTAMP         DEFAULT CURRENT_TIMESTAMP


TABLE 2: transactions

Field              Type              Constraints
------------------------------------------------------------
id                 INT               PRIMARY KEY, AUTO_INCREMENT
user_id            INT               NOT NULL, FOREIGN KEY
recipient          VARCHAR(100)      NULL
type               VARCHAR(20)       NOT NULL
amount             DECIMAL(12,2)     NOT NULL
status             VARCHAR(20)       NOT NULL
transaction_date   TIMESTAMP         DEFAULT CURRENT_TIMESTAMP


RELATIONSHIP

users.id
   |
   | 1 : Many
   |
   ▼
transactions.user_id


TRANSACTION TYPES

ADD_MONEY
SEND_MONEY


TRANSACTION STATUS

SUCCESS
FAILED


BUSINESS RULES

1. New users start with a balance of 0.00.
2. Add-money amount must be greater than 0.
3. Send-money amount must be greater than 0.
4. Send-money amount cannot exceed available wallet balance.
5. Every transaction belongs to a user.
6. Every successful transaction has a unique transaction ID.
7. Failed transactions must not modify the wallet balance.
